# 2–3 Minute Demo Script
Good morning. Our project is QueueLess AI.

We normally choose a queue by looking at how many people are standing in it. But the shortest queue is not always the fastest.

QueueLess AI predicts waiting time instead of simply counting people. Our lightweight machine-learning model considers queue length, average service time, time of day, arrival rate and counter efficiency.

In the demo, I can change the conditions for each counter. The model predicts expected waiting time and recommends the counter with the lowest predicted wait.

We selected AI/ML – Small / Efficient AI because this problem does not require a huge model. A lightweight tabular model can run with modest computing resources and can be retrained when real queue data becomes available.

This can be useful in college canteens, hospitals, banks, ticket counters and event registration.

In the future, QR check-ins, sensors and historical data can make the system real-time and more accurate.

**Don't just find the shortest queue — find the fastest one.**
Thank you.
