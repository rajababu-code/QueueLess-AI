# QueueLess AI – Project Report
## Abstract
QueueLess AI predicts expected waiting time and recommends the fastest expected queue using lightweight machine learning.

## Problem
Queue length alone is unreliable because service speeds and arrival patterns differ.

## AI/ML
A Random Forest regression model uses six queue/service features. The included dataset is synthetic for demonstration.

## Theme
AI/ML → Small / Efficient AI.

## Prototype metrics
MAE: 1.85 minutes; RMSE: 2.60 minutes; R²: 0.976.

## Future scope
Real observations, live sensors, QR check-ins, mobile app, admin dashboard and periodic retraining.
